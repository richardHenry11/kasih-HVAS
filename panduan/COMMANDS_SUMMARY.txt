================================================================================
ARDUINO MEGA 2560 PERIPHERAL CO-PROCESSOR - UART JSON+CRC16 CHEAT SHEET & SUMMARY
================================================================================

Physical Link : ESP32 UART <-> Arduino Mega UART0 (Pin 0 RX0, Pin 1 TX0 / USB)
Baud Rate     : 115200 bps (8 Data bits, No Parity, 1 Stop bit)
Delimiter     : Newline (\n)
Framing       : Single-line JSON + Modbus CRC16 (4 Hex characters, polynomial 0xA001)

--------------------------------------------------------------------------------
1. HARDWARE PIN MAPPING SUMMARY
--------------------------------------------------------------------------------
UART0 (115200) : Link ESP32 Main CPU (Pin 0 RX0, Pin 1 TX0)
UART1 (9600)   : Thermal Printer ESC/POS (Pin 19 RX1, Pin 18 TX1)
UART2 (9600)   : GPS NEO-M7 (Pin 17 RX2, Pin 16 TX2)
UART3 (9600)   : PZEM-004T v3.0 AC Meter (Pin 15 RX3, Pin 14 TX3)
I2C Bus        : RTC DS3231 (0x68), BME280 (0x76/0x77), AT24C64/AT32C64 (Auto 0x50-0x57)
OneWire        : DS18B20 Temp Probe (Pin A0 / Digital 54)
Interrupt 0    : AC Dimmer Zero-Cross Sync (Pin D2)
Timer1 PWM     : AC Dimmer TRIAC Gate Trigger (Pin D3)
Active Buzzer  : Non-blocking Beep Engine (Pin D22)
Voltage Sensor : DC Voltage Reader 0-25V (Pin A3 / Digital 57)

--------------------------------------------------------------------------------
2. COMPLETE CHEAT SHEET: LIST OF ALL 29 AVAILABLE COMMANDS
--------------------------------------------------------------------------------

[COMMAND]             [DESCRIPTION & PARAMETERS]
--------------------------------------------------------------------------------
1. ping               : Health check (Returns "pong" & mcu_uptime_ms)
2. get_system         : Full report of device uptime, boot count, run time, & module status
3. get_module_config  : Read module enable/disable config, boot count, & run time from EEPROM
4. set_module_config  : Enable/disable modules & save to EEPROM (Single / Batch Update)
5. get_rtc            : Read DS3231 RTC date, time, and temperature
6. set_rtc            : Set RTC date & time (via ISO string, timestamp, or fields)
7. get_bme            : Read BME280 temperature, humidity, and pressure (hPa)
8. get_gps            : Read GPS NEO-M7 connection, satellite fix, lat/lng, speed, UTC
9. get_ds18b20        : Read DS18B20 probe temperature & 64-bit ROM ID Hex
10. get_pzem          : Read PZEM-004T AC voltage, current, power, kWh, freq, PF
11. reset_pzem_energy : Reset PZEM-004T accumulated energy (kWh) to 0
12. get_printer       : Read Thermal Printer connection & paper status
13. print_text        : Print formatted text (text, align, bold, underline, size)
14. print_feed        : Feed paper N lines (lines)
15. print_raw         : Send raw ESC/POS Hex bytes to printer (hex)
16. get_dimmer        : Read AC Dimmer power percentage & Zero-Cross connection
17. set_dimmer        : Set AC Dimmer power percentage (percent: 0-100)
18. get_voltage       : Read DC voltage sensor on Pin A3 (adc_raw & voltage 0-25V)
19. set_buzzer        : Turn Active Buzzer ON (true) or OFF (false) on Pin D22
20. beep              : Trigger non-blocking beep pattern (count, on_ms, off_ms)
21. read_gpio         : Read pin digital logic, analog ADC, and voltage (e.g. 13 or "A3")
22. digital_read      : Alias for read_gpio
23. analog_read       : Read ADC & voltage specifically for analog pins
24. write_gpio        : Write pin digital logic HIGH/LOW (pin, val: 1/0, optional mode)
25. digital_write     : Alias for write_gpio
26. pwm_write         : Write PWM duty cycle (0-255) to PWM pin (pin, duty: 0-255)
27. set_pin_mode      : Set pin mode (pin, mode: "input", "output", "input_pullup")
28. start_stream      : Enable periodic automatic telemetry push (interval ms)
29. stop_stream       : Disable periodic telemetry push

4. COMPLETE ERROR CODE CHEAT SHEET
--------------------------------------------------------------------------------
INVALID_JSON                  : Payload bukan JSON valid.
CRC_MISMATCH                  : CRC16 Modbus (0xA001) yang dikirim ESP32 tidak cocok.
MISSING_CMD                   : Objek JSON tidak memiliki field wajib "cmd".
UNKNOWN_CMD                   : Perintah tidak dikenali oleh Arduino Mega.
BUFFER_OVERFLOW               : String JSON melebih 256 byte.
MODULE_DISABLED               : Perintah ditolak karena modul sedang DISABLED via EEPROM config.
MISSING_MODULE_CONFIG_PARAMS  : Field module/enabled/config tidak ada pada set_module_config.
MISSING_DATETIME_PARAMS       : Field datetime/timestamp tidak ada pada set_rtc.
MISSING_STATE_PARAM           : Field state tidak ada pada set_buzzer.
MISSING_PIN_PARAM             : Parameter pin tidak ada pada read_gpio / analog_read.
MISSING_PARAMS                : Parameter pin/val/duty/mode hilang pada write_gpio / pwm_write.
MISSING_TEXT_PARAM            : Text printer kosong pada print_text.
MISSING_HEX_PARAM             : Hex printer mentah kosong pada print_raw.
MISSING_PERCENT_PARAM         : Field percent tidak ada pada set_dimmer.
RTC_NOT_FOUND                 : Chip RTC DS3231 (0x68) terlepas dari I2C bus.
BME280_NOT_FOUND              : Sensor BME280 (0x76/0x77) terlepas dari I2C bus.
DS18B20_NOT_FOUND             : Probe DS18B20 terlepas dari Pin A0.
PZEM_NOT_FOUND                : Modul PZEM-004T di Serial3 tidak merespon Modbus RTU.
SET_RTC_FAILED                : Gagal menulis waktu baru ke DS3231.
